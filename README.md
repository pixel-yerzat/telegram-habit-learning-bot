# 🤖 Telegram Bot: Habit & Learning Tracker (Node.js + SQLite)

Многофункциональный Telegram-бот для планирования ежемесячных целей, ежедневного трекинга привычек, проверки усвоения учебных материалов (курсы, книги) и еженедельного анализа компетенций в виде радарной диаграммы (Radar / Spider Chart).

---

## 🌟 Основные возможности

### 1. 🎯 Ежемесячный набор челленджей (Monthly Intake & Быстрое добавление)
- **⚡ Добавление всех целей одним сообщением**: отправьте список целей сообщением (например, скопированный из заметок или списка задач), и бот автоматически распознает цели, типы, сферы компетенций и регулярность!
  ```text
  1. Курс по Node.js и базам данных
  2. Утренняя зарядка 20 мин
  3. 15 минут чтения на английском
  4. Читать книгу по системному дизайну
  5. Пить 2 литра воды
  ```
- Типы целей:
  - **🔥 Привычка (Habit)** — спорт, режим сна, медитация, питьевой режим.
  - **🧠 Обучение / Курс (Learning)** — программирование, языки, профессиональные курсы.
  - **⚡ Проект / Навык (Skill)** — пет-проекты, практика, творчество.
- Привязка к сферам компетенций: *Программирование*, *Здоровье*, *Английский*, *Чтение*, *Дисциплина*, *Продуктивность* или своя категория.

### 2. ⏰ Ежедневные напоминания и трекер
- **Утренний фокус (09:00)**: список активных целей на день и текущие стрики (огнеметы 🔥).
- **Вечерний чек-ин (21:00)**: интерактивные кнопки (✅ Выполнено / ❌ Пропущено) для быстрой фиксации результатов.
- Расчет непрерывной серии дней (стриков).

### 3. 🧠 Проверка знаний & Интерактивный AI-тест (Google Gemini)
- Для обучающих целей доступна проверка усвоения изученного материала с помощью ИИ (**Google Gemini**):
  - 🤖 **Интерактивный AI-тест (Quiz с вариантами ответов A/B/C/D)**: Gemini на лету генерирует персонализированный тест по изученной теме, дает мгновенную обратную связь с объяснением каждого правильного варианта и рассчитывает итоговый балл усвоения (1–10).
  - ✍️ **Метод Фейнмана & Развернутый ответ**: объясните тему своими словами или ответьте на контрольный вопрос, а ИИ оценит глубину понимания, выделит сильные стороны и укажет на нюансы, которые стоит повторить.
- Результаты проверок автоматически засчитывают выполнение привычки за день и влияют на еженедельный радар компетенций!

### 4. 📊 Еженедельный анализ компетенций и Радарная диаграмма (Radar Chart)
- Каждое воскресенье в 20:00 бот формирует детальный срез прогресса.
- Расчет процентного прогресса по каждой компетенции на основе выполненных привычек и оценок понимания.
- **Построение Spider / Radar Chart**: наложение прогресса текущей недели на предыдущий чекпоинт (визуализация роста и дельты: +15%, +10%).
- Выделение сильных сторон недели и зон роста на следующий период.

## 🛠 Стек технологий

- **Node.js** (v18+) (ES Modules)
- **Telegraf 4.x** (фреймворк для Telegram-бота)
- **Google Gemini API (@google/generative-ai)** (генерация адаптивных тестов и ИИ-рецензирование ответов)
- **Better-SQLite3** (высокоскоростная встраиваемая база данных SQLite)
- **Node-Cron** (планировщик ежедневных и еженедельных задач)
- **QuickChart / Chart.js** (генерация визуальных радарных диаграмм)
- **Day.js** (работа с датами, ISO-неделями и часовыми поясами)

## 🚀 Быстрый запуск

### 1. Установка зависимостей
```bash
npm install
```

### 2. Настройка переменных окружения
Откройте файл `.env` (или скопируйте из `.env.example`):
```env
BOT_TOKEN=123456789:ABC-DEF1234ghIkl-zyx57W2v1u123ew11
DB_PATH=./data/bot.sqlite
DEFAULT_TIMEZONE=+05:00
DEFAULT_MORNING_REMINDER=09:00
DEFAULT_EVENING_REMINDER=21:00
```
> Получите `BOT_TOKEN` у официального бота [@BotFather](https://t.me/BotFather) в Telegram.

### 3. Запуск бота
```bash
# Обычный запуск
npm start

# Режим разработки с автоперезагрузкой (watch mode)
npm run dev
```

### 4. Запуск тестов
```bash
npm test
```

## 📱 Команды бота

| Команда | Описание |
|---|---|
| `/start` | Приветствие и знакомство с функционалом |
| `/challenges` | Просмотр целей месяца и прогресса |
| `/add` | Интерактивный пошаговый мастер добавления цели |
| `/checkin` | Чек-ин привычек за сегодняшний день |
| `/quiz` или `/review` | Проверка усвоения изученного материала |
| `/weekly` или `/diagram` | Формирование еженедельного анализа и построение радарной диаграммы |
| `/settings` | Настройка времени напоминаний и часового пояса |
| `/help` | Справочная информация |

## 🗄 Структура базы данных (SQLite)

- `users` — профили пользователей, настройки времени напоминаний, таймзона.
- `challenges` — ежемесячные цели, категории, целевая частота, типы.
- `daily_logs` — ежедневные отметки выполнения (`completed`, `skipped`), заметки.
- `knowledge_checks` — проверенные темы, контрольные ответы, баллы усвоения (1–10).
- `weekly_checkpoints` — еженедельные срезы компетенций в JSON, сильные стороны, динамика.
